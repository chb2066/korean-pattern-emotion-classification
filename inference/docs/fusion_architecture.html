이미지+텍스트 융합 구조 - Self-Attention과 앙상블

이미지 브랜치는 DINOv3를 완전히 얼린 채로 쓰고, 텍스트 브랜치(5개 아키텍처)는 end-to-end로 fine-tuning한다. 둘을 토큰 2개짜리 시퀀스로 묶어 self-attention 한 층을 태우는 게 핵심 - Q, K, V가 전부 같은 2-토큰 시퀀스에서 나온다.

1. 단일 모델 파이프라인

텍스트 인코더 하나(예: klue-roberta-large) 기준. 5개 아키텍처가 이 구조를 독립적으로 반복한다.

2. 앙상블 - 5개 모델 → 가중합

위 파이프라인을 서로 다른 텍스트 아키텍처 5개로 독립 학습시킨 뒤(전부 description만 입력, 전체 fine-tuning), 확률을 가중합한다 (post-hoc, late fusion - 학습 중 서로 상호작용하지 않음).
