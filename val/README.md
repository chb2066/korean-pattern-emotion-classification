# Validation 결과 분석

`analyze_val.py`로 val set(446장) 기준 최종 앙상블(F1@5=0.8000) 예측을 라벨별/샘플별로 뜯어본
결과 요약. 재현하려면 `../train/`에서 `ensemble.py`가 먼저 정상 실행되어 `features/*_val.npz`가
있어야 함 (이미 포함되어 있어 바로 실행 가능).

```bash
python analyze_val.py
```

## 핵심 결과

- 샘플당 5개 중 4개 이상 맞춘 비율 77.1%(4개 50.4% + 5개 26.7%), 완전 오답(0/5)은 0장
- 라벨별 F1 편차 큼: 최고 풍성한(0.909)/단순한(0.893) vs 최저 신비한(0.656)/고급스러운(0.660)
- 편차는 GT 개수 문제 아님 — 우아한(GT 126장)도 낮고, 익살스러운(GT 9장)은 오히려 높음(0.824)
  → 개념이 애매한(추상적인) 라벨일수록 저조
- 혼동 분석: 신비한/고급스러운/현대적인/우아한/유려한을 놓칠 때 대신 예측되는 라벨은
  압도적으로 "조화로운"(GT 291, 최다)·"고전적인"(GT 273, 2위)
  → 모델이 확신 없을 때 고빈도 라벨로 쏠려서 의미 가까운 세밀한 라벨의 자리를 빼앗는 패턴
- 5개 모델 top5 예측 자카드 유사도 0.74~0.79로 꽤 높음 — 앙상블 이득은 "전혀 다른 예측"이
  아니라 "애매한 경계에서의 미세한 확신 차이"에서 나옴

**결론**: 모델 자체는 안정적(완전 오답 0건). 추가 개선하려면 모델보다 애매한 라벨(우아한/
고급스러운/신비한 등)의 정의·가이드라인 정비가 더 레버리지가 클 수 있음.
